# 📊 Dashboard Screenshots

This folder contains screenshots of the **8 interactive Power BI dashboards** developed for the **Banking Fraud & Financial Risk Intelligence Platform**.

The dashboards provide executive and analytical views of banking transactions, Anti-Money Laundering (AML) activity, fraud patterns, customer behavior, bank performance, payment activity and financial transaction networks.

---

## 📊 Dashboard Portfolio

### 1️⃣ Executive Risk Command Center

Provides a high-level overview of the banking ecosystem, including transaction activity, transaction value, laundering indicators, banks and payment trends.

**Key Focus:**
- Executive-level KPIs
- Transaction activity
- AML indicators
- Bank performance
- Payment trends

---

### 2️⃣ Fraud Intelligence Center

Provides detailed monitoring of suspicious transactions and Anti-Money Laundering (AML) activity.

**Key Focus:**
- Laundering transactions
- Laundering rate
- Suspicious accounts
- Laundered amount
- Fraud transactions
- Suspicious transaction monitoring

---

### 3️⃣ Investigation Workspace

A dedicated Power BI **drill-through dashboard** for investigating individual suspicious transactions.

**Key Focus:**
- Selected transaction
- Sender and receiver accounts
- Associated bank
- Transaction amount
- Payment method
- Currency
- Fraud status

---

### 4️⃣ Customer & Account Intelligence

Provides customer-centric analysis of transaction behavior, account activity and customer performance.

**Key Focus:**
- Customer activity
- Account activity
- Transaction behavior
- Customer segmentation
- High-risk accounts
- Transaction value

---

### 5️⃣ Bank Performance Intelligence

Analyzes banking institution performance and financial risk across multiple banks.

**Key Focus:**
- Transaction volume
- Transaction value
- Bank rankings
- Laundering rate
- Laundered amount
- High-risk banks
- Cross-bank comparison

---

### 6️⃣ Payment & Transaction Analytics

Analyzes transaction activity across payment methods, currencies and transaction channels.

**Key Focus:**
- Payment method distribution
- Transaction value

- Currency analysis
- Daily transaction trends
- Payment channel performance

---

### 7️⃣ Network & Relationship Analysis

Provides analytical insights into relationships and connectivity within the financial transaction network.

**Key Focus:**

- Network activity
- Entity relationships
- Financial transaction patterns

---

### 8️⃣ Executive Risk Intelligence Dashboard

Provides an executive-level view of financial risk indicators and banking intelligence for strategic monitoring and decision-making.

**Key Focus:**
- Risk indicators

- Banking performance

- Executive-level insights

## 🔍 Interactive Power BI Features

The dashboards use Power BI functionality to support interactive analysis, including:

- KPI cards
- Interactive slicers
- Cross-filtering
- Drill-through analysis
- Dynamic visualizations
- Conditional formatting
- Ranking analysis
- Detailed transaction tables
- Interactive bank and currency filters

---

## 📈 Key Analytical Insights

The dashboards provide visibility into important findings from the analytical dataset, including:

- **5.08M+ banking transactions** processed
- **166K customers**
- **519K accounts**
- **30K banks**
- **5,177 laundering transactions**
- **3,376 suspicious accounts**
- **0.10% overall laundering rate**
- **22.90T total transaction amount**

The dashboards also identify high-performing banks, laundering activity, suspicious payment methods, dominant currencies and other financial risk indicators.

## 🎯 Purpose

These screenshots provide a visual representation of the Power BI reporting layer of the project.

They demonstrate how the processed analytical data, SQL analysis and DAX measures are transformed into interactive business intelligence dashboards for:

- Fraud investigation
- AML monitoring
- Financial risk analysis
- Customer intelligence
- Bank performance analysis
- Transaction analytics
- Executive decision-making
