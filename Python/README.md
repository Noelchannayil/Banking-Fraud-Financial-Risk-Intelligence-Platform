# 🐍 Python ETL & Feature Engineering

This folder contains the Python scripts developed for the **Banking Fraud & Financial Risk Intelligence Platform**.

The Python layer implements the project's end-to-end ETL pipeline, including raw data auditing, data cleaning, validation, feature engineering and analytical dataset creation.

The processed datasets generated by this pipeline are subsequently used by the **MySQL database**, **SQL analytics layer** and **Power BI dashboards**.
